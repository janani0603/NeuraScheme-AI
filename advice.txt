SECTION 12 — ELIGIBILITY SCORING ENGINE
--------------------------------------------------------------------------------

File: backend/app/services/eligibility_service.py

6 weighted factors:
  state:      25%  → Central = always match; State = check if state name in text
  occupation: 20%  → keyword maps for student/farmer/entrepreneur/etc.
  income:     20%  → checks for income-related keywords, then compares thresholds
  category:   15%  → SC/ST/OBC/EWS/General keyword matching
  education:  10%  → keyword maps for 10th/12th/diploma/graduate/etc.
  tags:       10%  → disability, gender (female), student, farmer flags

Scores are 0.0–1.0 per factor, multiplied by weight, summed → 0–100.
Confidence score = eligibility_score * (0.6 + 0.4 * profile_completeness), capped at 100.
MIN_SCORE threshold = 40.0 (schemes below this are excluded from results).

Profile completeness is based on 7 fields: state, gender, occupation, education,
annual_income, category, age.

SECTION 13 — AI PIPELINE (LangGraph)
--------------------------------------------------------------------------------

File: backend/app/agents/workflow.py

Graph nodes (in order):
  1. profile_agent     → validates/normalizes profile, sets profile_valid flag
  2. retrieval_agent   → MongoDB Atlas Vector Search → fallback text search
  3. eligibility_agent → rule-based scoring + optional Gemini assist for borderline
  4. recommendation_agent → combined score + Gemini re-ranking of top 20
  5. explanation_agent → Gemini explanations for top 10, fallback for rest

Conditional edges:
  - profile → END if profile_valid is False
  - retrieval → END if no candidates found
  - eligibility → END if no scored schemes
  - recommendation → explanation → END (always)

AgentState TypedDict fields:
  user_id, profile, question, conversation_id,
  profile_valid, profile_completeness, candidates, scored_schemes,
  ranked_schemes, explanations, final_recommendations, assistant_response, error

Combined score formula (recommendation_agent):
  (eligibility_score/100 * 0.60) + (vector_score * 0.25) + (completeness * 0.15)

Gemini is called for:
  - Borderline eligibility interpretation (score 35–45, eligibility text > 100 chars)
  - Re-ranking top 20 schemes (ranking_prompt)
  - Explanations for top 10 schemes (explanation_prompt)
  - All assistant chat responses (assistant_prompt)

All Gemini calls have try/except with fallback — pipeline never crashes on Gemini failure.
